# Test Scenarios – Login & Registration Testing Project

A **Test Scenario** is a high-level statement of "what to test." Each scenario below
is later broken down into detailed Test Cases in `03_Test_Cases.md`.

| Scenario ID | Test Scenario |
|---|---|
| TS-01 | Verify user can register successfully with valid details |
| TS-02 | Verify registration form validates empty fields |
| TS-03 | Verify registration form validates email format |
| TS-04 | Verify registration form validates password length |
| TS-05 | Verify registration form validates password and confirm password match |
| TS-06 | Verify duplicate email cannot be registered twice |
| TS-07 | Verify password show/hide toggle works on Registration page |
| TS-08 | Verify user can log in successfully with valid, registered credentials |
| TS-09 | Verify login form validates empty fields |
| TS-10 | Verify login shows proper error for invalid/incorrect email |
| TS-11 | Verify login shows proper error for incorrect password |
| TS-12 | Verify password show/hide toggle works on Login page |
| TS-13 | Verify Forgot Password link behavior |
| TS-14 | Verify Dashboard displays the logged-in user's name |
| TS-15 | Verify Dashboard cannot be accessed without logging in |
| TS-16 | Verify Logout functionality works correctly |
| TS-17 | Verify navigation links between Login and Registration pages work |
| TS-18 | Verify basic UI/layout is clean and consistent across pages |
